# Carbon Kingdom — Teacher's One-Page Guide

**What it is:** a 5-level web game that teaches IUPAC organic-chemistry
naming rules (longest chain → numbering direction → double/triple bonds →
substituent naming → full names). No installs for students — it runs in
any phone/laptop browser, no login required.

## Running a class session

1. On the classroom screen/projector, open the game's link and add
   **`#teacher`** to the end of the URL (e.g. `...your-link.../#teacher`).
2. Choose **แข่งขันทั้งห้อง (Class Race)** for everyone racing individually,
   or **ศึกทีมปะทะทีม (Team Battle)** to auto-split the class into Team A /
   Team B. Click **สร้างห้อง (Create room)** — a 6-digit code appears big.
3. Tell students to open the game link on their own device, enter a
   nickname + pick an avatar, choose **เข้าร่วมห้องเรียน (Join a classroom
   room)**, and type in the code.
4. Once you see everyone's name appear on your dashboard, click **เริ่มเกม
   (Start game)** — every student's screen moves on automatically.
5. Play until the class is done, or click **จบเกม (End game)** any time.

If you'd rather skip rooms entirely, students can just pick **เล่นคนเดียว
(Play solo)** and play independently — the levels, scoring, and their own
end-of-game report work exactly the same without a room.

## What you'll see on your dashboard, live

- **Live leaderboard** — every joined student, current score, team badge if
  applicable.
- **Progress grid** — a row per student, a dot per level (L1–L5): grey = not
  started, orange = in progress, green = completed. A glance tells you who's
  behind.
- **Most-missed questions** — every wrong answer across the whole room,
  ranked, with the level and a short snippet — this is your "what to
  re-teach" list.
- **🚨 red banner** — any student who just got 3 wrong answers in a row.
  That's your cue to walk over.

## After class

Each student can open **📊 ดูรายงานของฉัน (View my report)** from their own
level picker for a personal breakdown: accuracy per level, total score,
badges earned, and a note on which level(s) to review (anything under 70%
accuracy). They can **Export CSV** (to email you, or drop in a spreadsheet
for your gradebook) or **Print / Save PDF** it directly.

## Good to know

- No student accounts, no data leaves the device unless you set up the
  optional real-time backend (see `SETUP.md` — by default, rooms only sync
  between browser tabs on the same computer, which is fine for one shared
  classroom screen or for a quick trial; ask whoever set up the game if you
  need students on their own separate phones/laptops to sync live).
- Every question's answer key was generated by an actual rule-checking
  program, not typed by hand — see `SETUP.md` if you (or your IT support)
  ever want to add more questions.
- The whole game works in Thai by default; every piece of UI text also
  exists in English if you ever need to switch (`SETUP.md` has the one-line
  change).
